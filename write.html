From draft to post / Vom Entwurf zum Beitrag

  1. Export your note. / Beitrag exportieren.
  2. Add the JSON file to content/notes/ in your website repository. / Die JSON-Datei im Website-Repository hochladen.
  3. The prepared GitHub Actions workflow builds the website after repository setup. / Der vorbereitete GitHub-Actions-Workflow erstellt die Website nach der Repository-Einrichtung.

Keep a copy before closing this page; drafts are not saved automatically. / Vor dem Schließen eine Kopie exportieren; Entwürfe werden nicht automatisch gespeichert.
